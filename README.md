## ✨ Features

- **5 Beautiful Pages:** Home, About, Services, Patient Stories, and Contact.
- **📱 Responsive Design:** Fully optimized for mobile, tablet, and desktop with a custom hamburger menu.
- **🎨 Stunning UI/UX:** Dark theme with warm teal accents, smooth scroll reveal animations, and animated counters.
- **📅 Functional Elements:** Appointment booking form with validation.
- **🗺️ Integrations:** Google Maps integration for clinic location.
- **❓ User-Friendly:** Interactive FAQ accordion section.

## 🛠️ Tech Stack

- **[React 19](https://react.dev/)** with TypeScript for robust component development.
- **[Vite 8](https://vitejs.dev/)** for lightning-fast build tooling.
- **[Tailwind CSS 4](https://tailwindcss.com/)** for rapid, utility-first styling.
- **[React Router DOM 7](https://reactrouter.com/)** for seamless client-side routing.
- **[Lucide React](https://lucide.dev/)** for beautiful, consistent icons.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repo
   ```bash
   git clone https://github.com/Sooraj-Suresh-Dev/Denta-Dental-Clinic-Website.git
   ```
2. Install NPM packages
   ```bash
   npm install
   ```

### Development

Run the development server locally:
```bash
npm run dev
```
Your app will be available at `http://localhost:5173`

### Build

Create a production-ready build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## 📂 Project Structure

```text
src/
├── components/      # Shared UI components (Nav, Footer, Layout)
├── pages/           # Page components (Home, About, Services, etc.)

├── imports/         # Static assets (images, icons)
├── App.tsx          # Root component containing routing logic
├── main.tsx         # Application entry point
└── index.css        # Global styles and Tailwind configuration
```
